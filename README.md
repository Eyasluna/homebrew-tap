# Eyasluna's Homebrew Tap

```bash
brew tap eyasluna/tap
brew install timesheet-automator
timesheet-automator
```

Or one-shot:

```bash
brew install eyasluna/tap/timesheet-automator
```

## Formulae

- **timesheet-automator** — biweekly timesheet generator. See [Eyasluna/timesheet-automator](https://github.com/Eyasluna/timesheet-automator).
